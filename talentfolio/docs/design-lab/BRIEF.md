# 기업 데스크 리디자인 — 공통 브리프 (시안 A/B/C 공용)

## 스쿼드 산출물 (UX 아키텍트 · 리서처 · UX 라이터 합의본)

**사용자**: 헤드헌터/기업 채용담당. 하루 여러 번 들어와 "오늘 내가 처리할 것"을 보고 승인한다. 모드 = Operate.
**루프**: 스카우트 건 입력 → 후보 탐색 → 핏 분석 → 헤드헌터 승인(HIL) → 제안 발송. 화면은 이 루프의 다음 행동을 앞에 둔다.

### 정보 구조 (4화면, 기존 라우트 기능 그대로)
1. **홈 /desk** — 오늘 처리할 것(승인 대기 수·답장 온 제안), 스카우트 건별 진행(매칭→분석→승인), 파이프라인 퍼널(가장 많이 빠지는 단계 표시), 수요·공급, 거절 사유, 활동 피드(에이전트/후보 응답/팀/주의).
2. **후보 /desk/candidates** — 핏 리포트 목록(점수·판정 strong/possible/weak), 필터, 승인/보류/거절.
3. **제안 /desk/offers** — 보낸 제안 상태(발송·열람·답장·수락/거절), 답장 먼저.
4. **회사 프로필 /desk/profile** — 회사 소개 편집.

실데이터 구조: `src/lib/deskApi.ts`(DeskSummary, DeskOffer, DeskFeedItem), `src/lib/deskData.ts`, `src/types` 의 FitReportRecord. 시안은 이 타입 그대로의 샘플 데이터(`src/app/lab/desk/_fixtures.ts`)로 그린다.

### 리서치 근거 (업계 B2B 대시보드 통용 조합)
- Linear·Vercel·Stripe·Attio 계열: 한 가지 바탕 + 잉크 + 액센트 1개, 표면은 톤 차이로 구분, 숫자는 tabular, 차트는 단색 계열 + 강조 1색.
- Figma 웹 트렌드 중 사용자 선호: #4·#8 (참고만, 그대로 따를 필요 없음). 키워드: 심플, 은은함, 감각적.
- 사용자 금지: "AI 느낌"(그라데이션 블롭, 글로우, 유리 블러, 아이콘 박스 카드 행, 작은 대문자 라벨, 이모지, 모노스페이스 장식, 01/02 번호).

### UX 라이팅 규칙
- 한국어, 짧은 평서문. 버튼은 동작 이름("승인", "제안 보내기"). 데모·테스트·샘플 티 나는 문구 금지.
- 판정 라벨: 잘 맞음 / 부분 일치 / 덜 맞음 (빨강 금지, 기호 병기).

### 기술 제약 (프론트엔드)
- Next 16 + React 19 + Tailwind v4. 차트는 **Recharts 3**(설치됨)만. ApexCharts 쓰지 말 것.
- 애니메이션은 anime.js v4 (`.claude/skills/anime-ui` 규칙). transform/opacity만, reduced-motion 대응.
- 폰트는 이미 로드된 것 우선(`src/app/fonts.ts`). 새 폰트가 필요하면 next/font/google 로 시안 폴더 안에서만.
- 접근성: 대비 AA, 포커스 표시, 키보드 조작, 폰 폭(390px) 가로 스크롤 없음.
