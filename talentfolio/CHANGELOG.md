## 2026-11-10
(브랜치: feat/account-auth)
- 제안 서신 화면 추가: 기업 `/desk/offers`, 구직자 `/studio/offers` — 메일 형식으로 주고받고 면접 시각 선택, 상태 색은 진행·좋은 소식·내 차례·끝남으로만 구분
- 스튜디오 포트폴리오 작업물 추가(`/api/profile/works`, StudioWorks) — 공개 버킷에 올리고 프로필에서 보여 줌
- 데스크 탭·헤더에 제안 서신 진입 추가, 스카우트 건 폼·승인함·인재 상세 화면 조정
- 공고 표준 양식 사본(`lib/postingFormat`)을 백엔드와 같은 규칙으로 맞춤
- 승인함(`/review`) 요약 아래에 점수 보정 내역 표시: 보정 전 점수 → 최종 점수와 사유를 보여 줘 헤드헌터가 점수가 낮아진 이유를 확인 가능 (`FitReport.calibration` 타입 추가)
- 기업 제안 서신: 서신을 열어 회신이 읽음 처리되면 목록의 새 회신 표시도 함께 갱신
- 디자이너 테스트 계정 시드 스크립트(`scripts/_seed_designer.mjs`) 추가 — 계정·비밀번호는 실행 인자로만 받음

## 2026-11-03
- 스튜디오 이력서: 프로필 사진 올리기·지우기 추가 — PNG/JPG/WEBP 5MB 이하, evidence 버킷 본인 폴더에 저장하고 경로는 계정 메타데이터에 보관, 보기는 1시간짜리 임시 주소로만
- 이력서 PDF 내보내기용 인쇄 전용 화면 추가 — 편집 UI 없이 값이 있는 항목만 표준 이력서 순서(사진·기본 정보·경력 합계·학력·자격증 등)로 출력
- 인쇄 스타일 추가: 인쇄할 때는 이력서 시트만 보이도록 A4 레이아웃 정리
- 스튜디오 상단에 로그아웃 버튼 추가
- 스카우트 건 만들기 폼 추가: 사람인 공고 항목(지역·경력·학력·고용형태·급여·마감)+본문 → AI 키워드 초안 → 손보기 → 공고만 등록 또는 바로 후보 찾기
- 인재 탐색을 데스크 인재 작업대로 일원화 — 회사 건 탭이 브라우저 저장 대신 서버 스카우트 건·담긴 후보(fit_reports)를 보여 주고, 옛 /discover 의 갈라진 흐름 정리
- 공고 표준 양식 사본(`lib/postingFormat`) 추가, JD 매칭 모달 입력도 같은 양식으로 합쳐 건 제목이 직군·핵심 기술로 잡히게 함
- 승인함: 스카우트 건 제목·고객사로 묶어 보이고, 발송 승인 전 후보에게 갈 본문을 미리 확인, 진행 중·실패 행도 목록에 유지
- 분석 실패(failed)·재시도 횟수 표시로 "분석 중"이 끝없이 보이지 않게 함
- 구직자 공고 화면: 추천 공고 4개 미리보기 + 전체 보기(?recs=all), 추천 공고도 칸에 담기 가능
- 빈 직함·소개가 모든 조건을 충족으로 잡던 매칭 버그 수정, 옛 테스트 모드 요약 문구는 화면에서 바꿔 표시
